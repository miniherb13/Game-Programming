## 7. PDF 만들기 (추천 순서)

### 방법 A — Word / 한글

1. `docs/final-report-draft.md` 내용을 Word에 붙여넣기  
2. 표지 서식, 그림 삽입, `[TODO]` 제거  
3. A4, 여백 2cm 전후, 10~11pt  
4. **PDF로 저장**  

### 방법 B — Google Docs

1. Markdown → Docs 붙여넣기 (표는 수동 정리)  
2. 팀 공유 편집 → PDF 다운로드  

### 방법 C — Pandoc (선택)

```powershell
pandoc docs/final-report-draft.md -o docs/final-report.pdf --pdf-engine=xelatex -V mainfont="Malgun Gothic" -V geometry:margin=2cm -V fontsize=11pt
```

한글 폰트·표 깨짐 시 Word 방식이 더 안전합니다.
